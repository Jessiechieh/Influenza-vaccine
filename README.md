# Influenza-vaccine

本專案已整理出高雄市流感疫苗合約院所的獨立網站頁面，並可直接用於 GitHub Pages。

## GitHub Pages 內容

- `index.html`：總覽頁面，列出所有院所並提供獨立頁面連結。
- `hospitals/`：每間院所一個獨立網站資料夾。
- `assets/style.css`：共用樣式。
- `data/hospitals.json`：抽取整理後的院所資料。

## GitHub Pages 使用方式

1. 將此 repo 推到 GitHub。
2. 進入 **Settings → Pages**。
3. 選擇 **Deploy from a branch**，分支選擇 `main`（或你的預設分支），資料夾選擇 `/ (root)`。
4. 儲存後等待 GitHub Pages 發佈。

發佈後可透過 `https://<your-account>.github.io/<repo-name>/` 檢視總覽頁。
